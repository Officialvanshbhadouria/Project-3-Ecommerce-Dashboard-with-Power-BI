<strong>E-Commerce Sales Dashboard | Power BI</strong>

Built an interactive E-Commerce Sales Dashboard using Microsoft Power BI to analyze sales, profit, products, customers, regions, and payment methods.

Key Features
📊 Sales, Profit, Quantity & Order KPIs
🛍️ Product and Category Performance Analysis
👥 Customer & Repeat Customer Analysis
🌍 State-wise Sales Performance
💳 Payment Mode & Profit Analysis
📈 Monthly Sales & Profit Trends
🔎 Top Products and Top Customers
💡 Business Insights & Strategic Recommendations
Tools & Skills

Power BI | DAX | Data Modeling | Data Visualization | Business Intelligence | Data Analysis

Key Insights

The analysis identified Electronics as the highest-performing category, while Beauty and Grocery showed comparatively lower performance. Maharashtra generated the highest sales among states, while customer and payment-mode analysis provided additional opportunities for business optimization.

Project Goal:
To transform raw e-commerce data into an interactive dashboard that helps businesses understand performance, identify trends, and make data-driven decisions.
